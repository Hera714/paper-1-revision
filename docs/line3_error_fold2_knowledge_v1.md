## 分析方式与主要发现

逐题检查了全部 49 题的原图、问题、选项、标准答案、原最终推理、缓存场景图及关系文字。主要问题不是单一的框偏差，而是模型把与问题不匹配的量当成结论：整体框替代局部内部空间、高度替代面积或体积、对齐替代距离与间距。部分图节点遗漏或定位错误，知识不能补回真实测量；另有少量标签、措辞或数值存在疑点。

知识包按八个主题统一注入，不按样本 ID 或答案分发，不给模型提供标准答案、原预测和本表。保留原框与关系，新增规则解释证据适用条件；不改路由、目标提取、深度估计和空间表征，不增加模型调用。

## 实现与运行

- 新知识：`knowledge_packs/line3_error_fold2_v1.json`。
- 独立入口：`scripts/replay_line3_error_fold.py`，沿用已使用的错误 fold 缓存回放协议，不修改共享模型代码。
- 每题保留原图、问题、四个选项、缓存场景图和关系文字，仅替换最终注入的知识；只调用一次最终推理。无选卡、无重新路由、无深度重算。
- 输出保留原始响应、最终 thinking、选项、缓存信息、知识文本及哈希；支持同设置断点继续。
- 标准答案和旧预测仅供输出评分，不拼入模型提示。

```bash
conda activate ovis
cd /root/autodl-tmp/paper-1-revision
export OMP_NUM_THREADS=8
python scripts/replay_line3_error_fold.py \
  --fold fold2 \
  --knowledge knowledge_packs/line3_error_fold2_v1.json \
  --output-dir outputs/line3_error_fold2_knowledge_v1_seed42
cat outputs/line3_error_fold2_knowledge_v1_seed42/summary.json
```
