## 推理方式与结果解释

`scripts/replay_line0_error_fold.py` 读取冻结fold和基线哈希，只进行图片+问题+选项+新知识的最终推理。每题一次模型调用；不运行路由、目标提取、深度或场景图构建。模型输入不含GT、基线预测、是否答错等评分字段。GT只用于生成后的评分。

种子42，每题使用42+整数ID，便于以后同条件重放。该随机数状态与旧全pipeline的全局随机数消耗不同，因此修正数量不等于知识的严格因果收益。此集合是错误开发集，也无法测出对原正确题的损害；后续完整路线验证仍需覆盖原正确题。

结果保存到 `outputs/line0_error_fold1_knowledge_v1_seed42/`：`manifest.json`记录来源、知识和代码哈希；`predictions.jsonl`保存问题、知识、完整输出和thinking；`summary.json`保存correct、corrected_ids与target_met。中断后同命令续跑，成功样本跳过，错误样本重试。

```bash
conda activate ovis
cd /root/autodl-tmp/paper-1-revision
export OMP_NUM_THREADS=8
python scripts/replay_line0_error_fold.py --fold fold1
```
