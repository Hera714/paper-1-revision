## 运行与解释

沿用 `scripts/replay_line0_error_fold.py`，显式指定fold2知识和独立输出目录。只进行图片、问题、选项、新知识的最终推理，每题一次。GT仅评分，不进入提示词。种子42，每题42+ID；与旧全pipeline随机数状态不同。错误集修正数量不能证明对整个路线净提升，后续仍须检查原正确题。

```bash
conda activate ovis
cd /root/autodl-tmp/paper-1-revision
export OMP_NUM_THREADS=8
python scripts/replay_line0_error_fold.py \
  --fold fold2 \
  --knowledge knowledge_packs/line0_error_fold2_v1.json \
  --output-dir outputs/line0_error_fold2_knowledge_v1_seed42
```

结果的summary.json包含correct、corrected_ids和target_met，predictions.jsonl保存完整知识及推理。中断后原命令续跑。
