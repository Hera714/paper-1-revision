## 推理命令与结果

```bash
conda activate ovis
cd /root/autodl-tmp/paper-1-revision
export OMP_NUM_THREADS=8
python scripts/replay_line1_error_fold.py \
  --fold fold3 \
  --knowledge knowledge_packs/line1_error_fold3_v1.json \
  --output-dir outputs/line1_error_fold3_knowledge_v1_seed42
```

每题复用基线scene_graph和spatial_relations_text，只进行一次最终图片+问题+选项+知识推理。GT只用于生成后的评分；无路由、选卡、深度估计或目标提取调用。seed为42，每题42+ID。原命令支持成功样本跳过和运行错误重试。

summary.json记录correct、corrected_ids和target_met，predictions.jsonl保存图、知识与完整thinking文本。当前是错误开发集，不能衡量对原正确题的损害；与旧pipeline随机状态不同，修正题数也不是匹配随机数条件下的纯知识因果效应。
