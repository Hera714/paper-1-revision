## 实验协议

脚本：`scripts/replay_line1_error_fold.py`。读取冻结基线与fold来源哈希；复用每题原scene_graph及spatial_relations_text，原样调用 `perform_final_reasoning(..., task_route='line1_base')`。每题一次最终推理，不提取目标、不估深度、不选路由、不选卡。输入只含图像、问题、选项、缓存表征、新知识，GT只在生成后评分。

种子42，每题42+ID。与原全pipeline随机数状态不同，修正数量尚不能认定为纯知识因果收益。错误集无法检测对原正确题的损害；后续完整路线评估需同时覆盖原正确题。

输出：`outputs/line1_error_fold1_knowledge_v1_seed42/`，包括manifest.json、predictions.jsonl、summary.json。保存完整原场景图、关系、知识文本、最终输出与thinking。summary每题更新，重复运行跳过成功样本、重试运行错误。

```bash
conda activate ovis
cd /root/autodl-tmp/paper-1-revision
export OMP_NUM_THREADS=8
python scripts/replay_line1_error_fold.py --fold fold1
```

查看 `summary.json` 的correct、corrected_ids、target_met。目标至少3题；达到目标不等于整个路线净提升。
