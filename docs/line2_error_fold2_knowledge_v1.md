## 推理与评估

独立脚本 `scripts/replay_line2_error_fold.py` 从line1已验证入口复制，改为强校验 `line2_orientation`、line2折目录及本折知识/输出默认值。原始场景图与spatial_relations_text逐条传入 `perform_final_reasoning(..., task_route='line2_orientation')`；每题一次最终推理，无路由、目标提取、深度、选卡或关系重算。

输入不含GT或原预测，评分在生成之后。seed42，每题42+ID。输出包含完整缓存表征、target_perspective、实际知识、完整输出和thinking。相同命令支持断点续跑；summary逐题更新。

```bash
conda activate ovis
cd /root/autodl-tmp/paper-1-revision
export OMP_NUM_THREADS=8
python scripts/replay_line2_error_fold.py \
  --fold fold2 \
  --knowledge knowledge_packs/line2_error_fold2_v1.json \
  --output-dir outputs/line2_error_fold2_knowledge_v1_seed42
```

summary.json中的correct与corrected_ids报告错误集修正数量，target_met判定是否至少3题。此错误开发集不能评估对原正确题的损害，且每题随机数状态不同于旧全pipeline，修正数量不是知识的严格因果净收益。
