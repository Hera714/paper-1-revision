## 运行协议

继续用 `scripts/replay_line2_error_fold.py`。只对本折46条错误题调用一次最终推理，原场景图、关系文本、路线不变；不重算路由、深度、目标或关系，也不选卡。GT与旧预测只写评分字段，不输入模型。seed42，每题42+ID。

```bash
conda activate ovis
cd /root/autodl-tmp/paper-1-revision
export OMP_NUM_THREADS=8
python scripts/replay_line2_error_fold.py \
  --fold fold3 \
  --knowledge knowledge_packs/line2_error_fold3_v1.json \
  --output-dir outputs/line2_error_fold3_knowledge_v1_seed42
```

summary.json记录correct、corrected_ids、target_met；predictions.jsonl保存完整新知识、缓存表征和最终thinking。原命令支持续跑。

错误集只反映原错误题的修正，不检测对原正确题的损害；与旧pipeline的随机数消耗不同，不能将所有修正直接归因于知识，完整路线净提升仍需后续验证。
